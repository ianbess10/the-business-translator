# Financial Markets Curriculum Architect

## Business Problem

Financial-market education requires complex technical and regulatory material to be translated into learning experiences appropriate to the learner's level.

The workflow demonstrates how AI can assist curriculum design while preserving educator authority.

## Workflow

```text
Syllabus
  ↓
Learning objectives
  ↓
Topic decomposition
  ↓
Bloom's Taxonomy mapping
  ↓
Lesson design
  ↓
Examples and scenarios
  ↓
Formative assessment
  ↓
Answer key
  ↓
Facilitator guide
  ↓
Educator review
```

## Evaluation

Score:
- factual correctness;
- alignment with learning outcomes;
- learner-level suitability;
- assessment quality;
- clarity;
- unsupported claims.

## Human Role

The educator validates content, learning design, context and final assessment decisions.

## Learner Principle

Prompt iterations are treated as a learning record: each failure is analysed and used to improve the next workflow version.
