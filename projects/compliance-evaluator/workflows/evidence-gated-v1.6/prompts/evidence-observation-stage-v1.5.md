# Bounded evidence observation stage v1.5

Match each supplied evidence item to one allowed approved requirement and report only its observed state. Use `present_deficient` when a supplied design artefact lacks required governance or design attributes, `missing` when the input explicitly marks the artefact missing, and `adverse_indicator_present` only when supplied records describe an actual adverse operating exception.

Do not decide mapping completeness, assurance outcome, severity, remediation, escalation or compliance. Do not invent requirement IDs or evidence IDs. Return one observation for every supplied evidence item and exactly the required JSON shape.
