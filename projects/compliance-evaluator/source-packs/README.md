# Controlled Source Packs

Source packs freeze the external regulatory material that an evaluation run is allowed to use.

Each pack records:

- the issuing authority and official source location;
- the source type and legal-status classification;
- publication, commencement, consultation and transition dates where available;
- version, amendment and supersession position;
- applicability questions against the frozen synthetic institution;
- permitted and prohibited uses;
- source-content hashes; and
- unresolved issues requiring human review.

The repository stores metadata and source pointers, not a substitute legal library. External documents must be retrieved from the recorded official location and their hashes checked before an evaluation run.
