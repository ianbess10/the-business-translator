# Independent Synthetic Holdout v1.0

This holdout was authored only after frozen v1.7 passed every regression gate. It contains 16 previously unexecuted case variants: eight source/applicability decisions and eight entered-assurance decisions. Identifiers and narrative formulations are new while the governing source pack, institution profile, rulebook and policy remain fixed.

Inputs and expected decisions are frozen before execution. The v1.7 workflow may be run against them once and evaluated once. No retry, repair, tuning, rerun or rescoring is permitted. Results are independent synthetic validation evidence, not production performance.
