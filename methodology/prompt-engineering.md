# Prompt Engineering Methodology

## 1. Understand
Define the business problem, user, workflow, constraints and decision boundary.

## 2. Baseline
Run an intentionally simple prompt to establish measurable starting performance.

## 3. Design
Introduce role, context, task instructions, constraints and output structure.

## 4. Test
Use representative, edge, ambiguous and adversarial cases.

## 5. Evaluate
Measure accuracy, completeness, source grounding, format compliance, unsupported claims and human usefulness.

## 6. Improve
Classify failures and change the prompt architecture rather than merely rewriting prose.

## 7. Govern
Define permitted actions, prohibited actions, escalation conditions, data controls and human authority.

## 8. Operationalise
Determine whether the capability is suitable for a controlled business workflow.

### Core principle

Prompt engineering is treated as a controlled business-process design activity, not as prompt decoration.
