# Failure Library

The portfolio treats failures as evidence.

Each failure should record:

1. input;
2. model output;
3. failure category;
4. business consequence;
5. likely cause;
6. prompt intervention;
7. revised output;
8. remaining risk;
9. human control.

Suggested categories:
- hallucination;
- missing context;
- incorrect classification;
- schema failure;
- source failure;
- ambiguity;
- instruction conflict;
- outdated information;
- inappropriate automation;
- human escalation missed.
