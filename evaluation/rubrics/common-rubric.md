# Common AI Evaluation Rubric

## 100-point framework

| Dimension | Weight |
|---|---:|
| Accuracy | 25 |
| Completeness | 15 |
| Source grounding | 15 |
| Output compliance | 10 |
| Hallucination control | 15 |
| Consistency | 10 |
| Human usefulness | 10 |

Weights should be adapted to the business risk of each use case.

## Pass principle

A high-quality output must be both useful and appropriately constrained. A fluent but unsupported answer is not a passing result.
